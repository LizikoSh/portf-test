# Єлизавета Соло Студіо — портфоліо з Pages CMS

**Почни з файлу [`ПОЧНИ-ТУТ.md`](ПОЧНИ-ТУТ.md).**

Це адаптована версія сайту `portfolio-liziko.vercel.app`: вона зберігає наявні HTML/CSS і додає керування вмістом через [Pages CMS](https://app.pagescms.org/), GitHub та Vercel **без чернеток, Supabase і сервера**.

Головні файли: `.pages.yml`, `content/galleries.json`, `content/pages/*.json`, `assets/js/portfolio-content.js`.

Оригінальний опис сайту збережений як `README-ORIGINAL.md`.
